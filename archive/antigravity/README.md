# Integraciones archivadas de Antigravity

Este directorio conserva el lanzador Antigravity y el cliente HarnessMix, incluidos ACP, terminal, modelos y pruebas. Está excluido del workspace activo y no es un proyecto compilable independiente.

Los archivos mantienen sus rutas originales dentro de este directorio. `integration-snapshots/` conserva copias de archivos compartidos antes de retirar sus puntos de integración; estas copias sirven como referencia para una posible extracción futura. El contenido puede trasladarse a otro proyecto o eliminarse cuando ya no se necesite.
